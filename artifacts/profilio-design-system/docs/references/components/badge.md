# Badge

## Source contract

- Source evidence: match-score, visibility, verification, and profile-state pills across `src/App.tsx`.
- Common states: public/verified/match, muted metadata, and peach attention.
- Behavior observed: compact, non-wrapping text; badges communicate status without taking over the hierarchy.

## Visual extraction

- Sage backgrounds signal positive or discoverable state.
- Peach supports attention and warm editorial emphasis.
- Marigold is reserved for active navigation and selected signal.

## Pilot implementation

The pilot uses the scaffold `Badge` family with token-driven default,
secondary, destructive, and outline states. Product-specific match-score
combinations remain documented here for the later chunk.
